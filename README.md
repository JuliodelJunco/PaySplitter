In many cases, like when you and your friends make a trip or when you go to a restaurant, you usually make all the persons of the group to contribute to pay those costs.

This project helps to do the management of the payments of these groups. This is done by letting the user do some tasks as: create a group with participants, add expenses and calculate the debts between participants.

The application, which was specifically designed as a mobile app for Android, was developed entirely in Java. For communication, it uses data sharing between Google accounts, avoiding the need for a centralized database to maintain the information of all potential customers. It consist of 9 screen, 21 classes, 157 methods y 4.368 lines of code.

In order to use it, you can download the APK here: [PaySplitter](https://github.com/JuliodelJunco/PaySplitter/raw/master/PaySplitter.apk).
